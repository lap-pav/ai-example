# Start Docker Containers
- Build and start all containers before initializing source code:
  ```sh
  docker-compose up -d --build
  ```

---

# Backend (Laravel API Only)
- Open a shell in the backend container:
  ```sh
  docker-compose exec backend bash
  ```
- Scaffold a new Laravel project in `/var/www` using the official command inside the container:
  ```sh
  composer create-project laravel/laravel /var/www
  ```
- Ensure the backend is API-only:
  - Remove or do not include any frontend scaffolding (no Blade views, no public JS/CSS assets).
  - Remove or skip `resources/views`, `public/js`, `public/css`, etc.
  - Configure `routes/api.php` for all endpoints.
  - Do not include web routes or controllers for web views.
- Prepare `.env` for Docker-based database and cache configuration.

---

# Frontend (Vue 3 Full Structure)
- Open a shell in the frontend container:
  ```sh
  docker-compose exec frontend sh
  ```
- Scaffold a new Vue 3 project in `/app` using the official command inside the container:
  ```sh
  yarn create vue /app
  # or
  npm create vue@latest /app
  ```
- When prompted, enable these features:
  - TypeScript
  - Vue Router
  - Pinia (state management)
  - ESLint/Prettier
  - Unit testing (if desired)
- Ensure the following structure is present:
  ```
  frontend/
    ├── src/
    │   ├── assets/
    │   ├── components/
    │   ├── views/
    │   ├── router/
    │   ├── store/ (or pinia/)
    │   └── main.ts
    ├── public/
    ├── package.json
    ├── vite.config.js
    └── ...
  ```
- The frontend should be ready for integration with the backend API.

---

# Conditions
- Initialize the backend and frontend source code inside the running Docker containers, ensuring all requirements above are met. 

- Run step by step if there is error, stop to fix the error
