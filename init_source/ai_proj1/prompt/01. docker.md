## Docker Structure

- The project uses a `docker-compose.yml` file (located in the `init_source/ai_proj1` folder) to orchestrate all services.
- All Docker-related configuration files (such as Dockerfiles, nginx configs, etc.) are organized under the `init_source/ai_proj1/docker` directory, grouped by service.

### Services

1. **Laravel PHP Container**
   - Runs the API only (no frontend assets).
   - Uses PHP 8.2-fpm.
   - Exposes port **9001**.
   - Uses **nginx** as the web server.
   - Runs **supervisor** for queue/work management.
   - Separate these setting in another file (don't run on dockerfile): install, migrate, seeder, clear cache
   - source code backend will be in `init_source/ai_proj1/backend`

2. **MySQL Container**
   - Uses MySQL version **8.0.36**.
   - Exposes port **9002**.

3. **Vue 3 Frontend Container**
   - Uses Node version **20.17.0-alpine3.20**.
   - Exposes port **9003**.
   - Uses **yarn** for package management and dev server.
   - source code frontend will be in `init_source/ai_proj1/frontend`

4. **Redis Cache**
   - Provides caching for Laravel.
   - Exposes port **9004**.

### Networking

- All containers are connected via a dedicated Docker network to enable communication between the frontend, backend, and database.

### File Structure

- `ai_proj1/docker/backend/` — Dockerfile, nginx.conf, supervisord.conf, and local_setup.sh for backend service.
- `ai_proj1/docker/frontend/` — Dockerfile for frontend service.
- `ai_proj1/docker-compose.yml` — Main compose file at the root of the `ai_proj1` folder.


### Conditions

- Source code in both backend and frontend will be initial inside docker container, so don't add any step that depends on source code when docker build
